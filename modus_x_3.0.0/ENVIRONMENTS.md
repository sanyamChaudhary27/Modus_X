# Environments

## Reported v3 TPU Runs

Kaggle TPU v5e-8; eight devices; Python 3.12-series runtime; JAX 0.10.2;
Optax 0.2.8; FP32 parameters/states; highest matmul precision. The exact Python
patch, NumPy and jaxlib versions are not consistently included in every pasted
result. Do not invent a full lockfile or infer TPU speed from CPU validation.

The Kaggle image supplies the TPU-compatible JAX stack. Use fresh notebooks;
do not acquire the same TPU from both kernel and subprocess.

## Release Preparation

See `docs/LOCAL_VALIDATION.json` for this session's actual CPU versions and
checks. The source tests run with CPU JAX on the local laptop; this is separate
from the reported TPU runtime. The paper compiles with Tectonic; its figures
are generated by matplotlib from normalized experiment records.

`requirements-cpu.txt` is a minimal installation guide, not a claim that arbitrary
future package versions reproduce the exact TPU artifacts.

# Modus_X 3.0.0

2026-10-24. New release directory: `modus_x_3.0.0/`. Root documentation,
metadata, model card, paper and explicit runner entry point now describe v3.
Older releases and frozen research sources are preserved unchanged.

Archive retention calibration, dependency-preserving two-stage chunk32 execution,
and causal local K/V filtering are specified and measured separately. The paper
reports both execution continuations, all three 25k endpoint pairs, audit hashes,
early-screen reversals and comparison boundaries. No long training was launched
as part of release packaging. The distribution contains source/evidence, not
the large trained checkpoint payloads. See ARTIFACT_GAPS.md.

Code remains MIT. Manuscript/new documentation are CC BY 4.0. Version DOI:
https://doi.org/10.5281/zenodo.23621101. Published venue/acceptance is not claimed.

# Claim boundary

Supported: recurrent state improves contiguous byte prediction; matrix and
vector components each have causal value; read, write, routing, and feedback
operations are not dormant. At the frozen seed-1 102.4M-character endpoint,
segment-scale retention also improved matched full-stream validation BPC and
strengthened the causal value and calibration of matrix-to-vector feedback.

Not supported: semantic long-term memory, optimal controller calibration,
matrix state being categorically more durable than vector state, or a claim
that continuous-stream BPC is directly interchangeable with reset-window BPC.
The paired coordination result does not by itself close the separate
over-retention replication lane.

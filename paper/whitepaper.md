# Current Modus_X Paper

The current paper is **Modus_X3: Calibrated Associative Memory and Efficient
Recurrent Execution**, by Sanyam Chaudhary, version3.0.0.

Read [the PDF](Modus_X_3.0.0_paper.pdf) or [the LaTeX source](manuscript/main.tex).
Version DOI: https://doi.org/10.5281/zenodo.23621101.

The old v2.1 manuscript is preserved under
`Modus_X_2.1.0/paper/`; it is not the current paper. The v3 release has its own
equations, diagram, three-seed endpoint evidence, execution measurements,
protocol history and comparison boundaries.
